PLANNING DE RÉVISIONS — VERSION JAVASCRIPT

Fichiers :
- index.html : structure du site
- style.css : design
- app.js : toute l'interactivité JavaScript
- manifest.webmanifest : permet l'installation comme petite web-app une fois hébergée

Fonctions JavaScript :
- cases à cocher interactives
- sauvegarde automatique dans localStorage
- XP et pourcentage de progression
- série de jours complétés
- modes Léger / Normal / Motivé
- ajout / modification / suppression de séances
- report d'une séance au lendemain
- calendrier cliquable
- suivi des chapitres
- export / import de la progression
- navigation entre plusieurs vues

Pour tester localement :
ouvre index.html dans un navigateur.

Pour publier gratuitement :
mets les 4 fichiers à la racine d'un dépôt GitHub Pages / Netlify / Cloudflare Pages.
